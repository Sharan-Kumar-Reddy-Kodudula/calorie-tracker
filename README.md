# Calorie & Nutrition Tracker

A single-page calorie and nutrition tracker that runs in your browser.

- Daily log by meal (breakfast, lunch, snack, dinner), with edit, copy-from-yesterday and saved meals
- Day summary, 7/14/30-day week view, daily targets
- Food database with a reference library (approximate values), barcode lookup (Open Food Facts), and label photo reading (Anthropic API, optional)
- Recipes built from saved foods
- Backup export/import (JSON)

## Important notes

- Data is stored in the browser you use. It is not synced between devices. Use Export backup to move data.
- Reference foods are approximate and are not verified against lab or USDA data. Check packages where you can.
- The label-reading feature needs your own Anthropic API key. The key is stored only in your browser.

## Use it

Open the GitHub Pages link for this repository in any browser, on phone or computer.
